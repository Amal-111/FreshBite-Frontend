# FreshBite – Frontend

FreshBite is a web application developed as part of the Advanced Web Applications course at King Saud University.

The platform is designed to help users discover and share healthy recipes through an organized and interactive recipe platform. Recipes are grouped into different categories, including seafood, meat, and vegan dishes, allowing users to easily explore recipes based on their preferences.

This repository contains the frontend implementation of the FreshBite project.

## Project Overview

FreshBite provides users with an interactive platform for browsing and managing healthy recipes. The system includes interfaces for user accounts, recipe categories, recipe details, personal recipes, and other user interactions.

The frontend focuses on the visual design, page structure, navigation, and client-side interaction of the platform.

## Key Features

- Browse healthy recipes by category
- View recipe details
- User registration and login interfaces
- Add and edit recipe interfaces
- View and manage personal recipes
- User profile and account interfaces
- Interactive and user-friendly web pages
