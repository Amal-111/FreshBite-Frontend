# FreshBite – Frontend

FreshBite is a dynamic web application for managing and sharing healthy recipes, developed as part of the Advanced Web Applications course at King Saud University.

This repository contains the frontend implementation of the FreshBite project, including the user interface and client-side components.

## Key Features

- Responsive user interface for browsing healthy recipes
- Recipe pages for different meal and recipe categories
- User registration and login interfaces
- Recipe creation, editing, viewing, and deletion interfaces
- User profile and recipe management pages
- Interactive client-side features using JavaScript

## Technologies

- HTML
- CSS
- JavaScript
